# odin-recipes

This is a recipe site project consist of a home page and three recipe pages linked to it. It shows a set of learned skills as follow:

- HTML5 fundamentals
- Semantic HTML
- Document structure
- Headings, paragraphs, lists and links
- Image integration and alt text
- Relative file paths
- Multi-page website structure
- Directory/file organization
- Basic website navigation
- Git & GitHub
- GitHub Pages deployment
- Debugging broken links and 404 errors
- Basic understanding of case-sensitive file paths
